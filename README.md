# 字幕对齐合并工具（Subtitle Align & Merge）

双版本 SRT 字幕对齐与合并的纯前端 Web 应用（React + TypeScript + Vite）。导入两份 SRT 后，可先做**时间轴校准**（自动锚点 + 分段线性映射，把版本 B 的时间轴校正到与 A 一致的时间基准），再按**时间重叠 + 文本相似度**进行顺序对齐，自动识别**一对一、一对多、多对一**以及单边片段；界面并排展示候选组与置信度，可逐组选择保留哪一版文本与时间轴，双侧组还支持**局部混编**（两侧拼接文本按 Unicode 字素做最长公共子序列：相同片段固定保留，差异片段逐段点选 A 或 B，立即生成本组文本），**未处理的冲突禁止导出**；工作区内还可以**重新校准并迁移审校决定**——保留旧对齐组与人工文本选择，对相同两份字幕用新校准重新对齐，先预览可迁移 / 歧义 / 无对应的旧组，确认后一次提交。合并结果可先做**滚动字幕消重**（识别连续滚动的同源字幕链并合并），再做**智能断行**（按显示宽度与行数限制自动分行），随后可在**阅读节奏**页签按 Unicode 字素统计每条的显示时长与字符/秒，把连续超限项划为区段并利用前后空隙联动调整时间边界（不改文本、不打乱顺序、时间不重叠），再到**镜头切点吸附**页签粘贴/上传每行一个 `HH:MM:SS,mmm` 的镜头切点列表，对切点附近的字幕边界用全局动态规划选择吸附或保留（保持顺序、相邻不重叠、每条不短于可调最小时长，依次最小化跨镜头字幕数、边界总位移与改动条数）；之后可在独立的**剪辑版字幕**页签逐行填写源片段起止毫秒（非负整数且起点小于终点，行序即成片顺序，允许重复、重叠、倒序），系统读取最终合并字幕（不改动原合并结果），把片段按原时长首尾拼接、对每条字幕与每个半开区间求交后平移到新时间轴，提供新时间轴预览与重新编号的独立 `edited.srt` 下载；还可在独立的**字幕遮挡避让**页签逐行填写遮挡区间的起止毫秒与位置（上/下），系统只读最终合并字幕，按半开区间相交判定被遮挡的轨道，为每条字幕在上、下两条轨道中全局择优分配（先最少化相邻切换轨道次数，再最少化改到上轨的条数，并列时按字幕顺序优先下轨），逐条预览轨道与遮挡依据，并独立下载含字幕序号、起止时间与轨道的 `tracks.csv`（不改变 SRT 本身；任一字幕两轨均被遮挡时展示首条无解原因且不导出部分方案）；此外还可在独立的**术语统一**页签粘贴/上传逐行用 Tab 分隔「原词⇥替换词」的术语表，系统只读最终合并字幕生成规范化副本（区分大小写、按 Unicode 字素字面量匹配，跳过 `<...>` 标签与换行建立匹配序列但原样保留，自左向右取当前起点最长原词、命中即越过该段且替换内容不再参与匹配），逐条展示前后文本与命中规则，独立下载时间与条数完全不变的 `terms.srt`；还可在独立的**审校定位**页签输入原文短语与允许跨条的最大时间间隔（非负整数毫秒），系统只读最终合并字幕即时定位对白：按 Unicode 字素区分大小写逐字匹配，字幕中的 `<...>` 标签与换行跳过但原样显示，标点与空格仍须逐字相同，短语可在间隔不超过阈值的相邻条目间延续（超阈必断，穿过无正文条目时逐跳检查），重复出现（含互相重叠）的命中全部列出，逐项展示起止条目、时间范围与各条命中字素高亮，短语为空或间隔无效时说明原因并清空命中，检索只读最终结果、不改合并 SRT；最终重新编号并校验时间单调性后下载为标准 SRT。无需任何外部服务，全部计算在本地完成；首次对齐与重新校准的迁移预览计算均放在 Web Worker 中执行，计算期间页面保持可响应，可随时取消，迟到的计算结果不会影响后续操作（详见下文「后台计算（Web Worker）、取消与错误处理」）。

## 一键启动（Docker）

```bash
docker compose up --build
```

启动后浏览器访问：**http://localhost:8080**（宿主机端口 `8080` → 容器内 nginx `80`），无需任何后端、外部服务或额外配置（镜像构建时自动执行 `npm ci` 安装依赖、`npm run build` 产出静态文件并由 nginx 托管，启动即用）。

页面入口用法：

1. 导入两份字幕后进入「时间轴校准」，点「应用校准并开始对齐」（或「恢复原始 B 时间并对齐」）进入工作区。
2. 工作区顶部「**重新校准并迁移决定**」按钮：保留当前对齐组与人工文本选择，回到校准页调整锚点/参数；点「应用新校准并预览迁移」（或「用原始 B 时间重新对齐并预览」）后弹窗预览，确认迁移才替换工作区，取消则旧工作区原样保留。
3. 工作区顶部「时间轴校准」按钮是放弃当前工作区、重新开始校准；「重新导入」回到导入页。

### 后台计算（Web Worker）、取消与错误处理

- **计算在 Worker 中进行**：首次顺序对齐与重新校准时的「对齐 + 迁移预览」都在 Web Worker 内执行（直接复用同一套对齐、置信度与迁移判定代码，结果与主线程计算完全一致），计算期间页面不冻结，可继续滚动、调整锚点参数或切换操作；Worker 每次发起时新建、任务结束（成功 / 失败 / 取消 / 被新计算顶替）后立即 `terminate()` 释放。
- **忙碌状态与取消**：计算中按钮区显示忙碌提示与「取消对齐 / 取消计算」（迁移弹窗中为「取消计算（保留旧工作区）」），点取消即终止 Worker、结束忙碌并留在当前页面。
- **这些操作也会终止旧计算**：返回导入页、在导入页修改任一侧字幕、加载示例数据、发起一次新的对齐 / 迁移预览。旧 Worker 迟到的成功或失败回执一律丢弃——**不会切换页面、不会覆盖已有结果，也不会清掉新任务的忙碌状态**。
- **迁移预览不改变旧工作区**：预览计算期间与弹窗打开时，旧对齐组、人工决定及消重 / 断行 / 节奏 / 吸附等下游采纳全部原样保留；取消后人工决定与下游采纳都不丢失；只有点「确认并一次提交」才按现有规则一次性写入新对齐与迁移结果。
- **生效校准信息与预览草稿分离**：工作区顶部的「✓ 时间轴已校准（N 锚点）/ 使用原始 B 时间」标识只反映**已确认提交**的校准（锚点数在提交时固化）。进入「重新校准并迁移决定」后修改锚点勾选或筛选参数、预览计算中、计算失败或点取消返回，该标识、锚点数、实际生效的 B 时间轴与审校决定都保持原样，不会被尚未提交的草稿带变；迁移预览弹窗在计算中 / 失败时也只显示**发起该次预览时**固化的校准参数（「按新校准（N 个锚点）」或「按原始 B 时间」），失败后的「重新计算」与「取消」照常可用。只有点「确认并一次提交」后，顶部标识才与新生效的 B 时间轴一起更新——确认新校准则显示新锚点数，确认「用原始 B 时间」重新对齐的预览则显示「使用原始 B 时间」（未校准）。
- **错误处理**：Worker 无法创建（浏览器限制等）或计算抛错时，页面显示失败原因、结束忙碌状态并允许再次发起（迁移弹窗内提供「重新计算」），已有工作区与输入内容保持原样；迁移规模超限时仍按原规则在预览中提示「无法在合理时间内完成全量最优匹配判定」。

> 旧版 Compose 可使用 `docker-compose up --build`。若 8080 端口被占用，修改 `docker-compose.yml` 中 `ports` 左侧端口即可。停止：`docker compose down`。

## 使用流程

1. **导入双版本**：为版本 A / B 分别选择、拖入或粘贴 SRT 内容（可点击「加载示例数据」快速体验）。
2. **时间轴校准（可选，推荐）**：点击「下一步：时间轴校准」进入校准页（或「跳过校准，直接对齐」）。系统自动筛选高相似锚点、剔除顺序冲突/时间重复/异常偏移，用至少两个锚点对版本 B 的时间做**分段线性映射**；表格展示每个锚点的 A 参考时间、B 原时间、B 新时间、漂移量与留一法残差，可勾选禁用/启用单个锚点并即时重算。参数（最低相似度、最短文本、偏移容忍）可调；**只有点击「应用校准并开始对齐」才会用校准后的 B 时间替换对齐输入**，点击「恢复原始 B 时间并对齐」可一键放弃校准，工作区内也可随时返回本页重新校准。
3. **顺序对齐**：点击「应用校准并开始对齐」（或「跳过校准，直接对齐」）后，对齐在后台 Web Worker 中执行，页面显示忙碌状态且保持可响应，可随时点「取消对齐」终止；计算完成后进入工作区，系统生成对齐组，每组标注类型（一对一 / 一对多 / 多对一 / 仅 A / 仅 B）与综合置信度（文本相似度 60% + 时间重叠 40%）。Worker 创建或计算失败时显示原因，可在调整后再次发起。
4. **解决冲突**：文本不一致或一对多 / 多对一的组会被标记为冲突（红色边框）。逐组选择保留的文本（A / B / **局部混编** / 自定义）与时间轴（A / B / 并集 / 自定义），或用工具栏批量操作（全用 A/B、用较长文本、按建议解决全部）；单边片段可选择保留或丢弃。
   - **局部混编**：点「局部混编」后，系统把该组两侧拼接文本按 Unicode 字素求最长公共子序列（LCS），**相同片段固定保留**，**差异片段**（含单侧插入、删除）逐段展示 A / B 两个可点选项（该侧无此片段时以 `∅` 表示，选中即删除该段）；逐段点选即时生成该组文本并在卡片内预览，该组随即作为**已解决冲突**进入右侧实时预览、时间校验与 SRT 导出。多条最优 LCS 路径按“匹配位置先 A 后 B”的字典序固定，重复词不会使片段边界漂移。改选整组 A / B / 自定义、或重新对齐（含重新校准迁移）时旧的逐片段选择自动清除。
   - **重新校准并迁移决定（可选）**：冲突解决到一半时若想调整校准，点工作区顶部「重新校准并迁移决定」进入校准页（旧对齐组与人工文本选择保留）。调整锚点或参数后点「应用新校准并预览迁移」（也可用「用原始 B 时间重新对齐并预览」放弃校准），系统对相同两份字幕重新对齐并弹出预览，分为**可迁移 / 歧义不迁移 / 无对应**三类；确认后一次提交，取消则旧工作区完全不变。迁移规则见下文「重新校准迁移说明」。
5. **滚动字幕消重（可选）**：切换到「滚动字幕消重」页签，设置**最大相邻间隔**（默认 1.0 秒，下一条开始与上一条结束之差，支持时间重叠的负值）与**最小文本重叠**（默认 2 字）。系统在当前合并结果上识别连续滚动字幕链，展示原链各条、合并文本与节省字符数；可逐链「采纳 / 恢复」，也可「全部采纳 / 全部恢复」。修改参数后链即时重算，未采纳或已恢复的链不影响结果。
6. **智能断行（可选）**：切换到「智能断行」页签，设置每行最大宽度与最多行数后，逐条预览原文与断行结果。可单条「应用 / 恢复」，也可「全部应用 / 全部恢复」；无法满足限制的条目会标明原因并保持原文。断行只影响导出文本，不改变对齐、消重与冲突解决结果。
7. **阅读节奏（可选）**：切换到「阅读节奏」页签，设置**最大字符/秒**（默认 20）与**最短 / 最长时长**（默认 1.0 / 7.0 秒）。系统在当前（已采纳消重与断行后的）结果上按 Unicode 字素统计每条的显示时长与字符/秒，把连续超限项划为区段，利用区段前后空隙联动调整边界给出修复；界面逐段对比原/新时间与速率，可逐段「采纳 / 恢复」或「全部采纳 / 全部恢复」，无解区段会明确标记原因并保持原时间。
8. **镜头切点吸附（可选）**：切换到「镜头切点吸附」页签（位于「阅读节奏」之后、右侧「校验导出」之前），在文本框**粘贴或点击「上传切点文件」**导入镜头切点列表，每行一个 `HH:MM:SS,mmm`（兼容 `MM:SS,mmm`、小数点与 1~3 位毫秒，自动升序去重，非法行逐行标出）。设置**吸附阈值**（默认 0.5 秒）与**最短时长**（默认 1.0 秒）后，系统对距切点不超过阈值的字幕开始/结束边界用全局动态规划在吸附与保留之间做选择，硬约束为保持顺序、相邻字幕不重叠且每条不短于最短时长，目标按字典序依次最小化：① 跨镜头字幕数；② 边界总位移；③ 改动条数。列表逐条展示原/新时间、命中切点、位移与未吸附原因（阈值内无切点 / 吸附后短于最小时长 / 会与相邻条重叠 / 未跨切点吸附只增加位移等），可逐条「采纳 / 恢复」或「全部采纳 / 全部恢复」；切点、参数或上游结果变化时旧采纳自动失效。
9. **校验导出**：右侧实时预览合并结果（含已采纳的消重链、已应用的断行、已采纳的阅读节奏时间与切点吸附时间）。存在未解决冲突或时间校验错误（开始时间倒退、区间重叠、时长非正、自定义时间非法）时无法导出；可勾选「自动修复时间重叠 / 非单调问题」。全部通过后点击「下载合并 SRT」，序号从 1 重新编排，导出始终使用已采纳消重、已应用断行、已采纳节奏修复与切点吸附的当前结果。
10. **剪辑版字幕（可选，独立模块）**：切换到「剪辑版字幕」页签，在文本框**逐行填写源片段起止毫秒**（每行两个非负整数，起点严格小于终点；支持空格/Tab、逗号、中文逗号、分号等分隔，也可上传文本文件）。**行序即成片顺序**，允许重复、重叠、倒序片段；系统**只读**当前最终合并字幕（不会改动原合并结果），立即重算：片段按各自原时长首尾拼接，对每条字幕与每个半开区间 `[起点, 终点)` 求交，仅保留正时长交集，裁切后的时间减去片段起点、再加上此前片段总时长，文本原样复制。页面给出每个片段的成片落点、命中条数（空白片段明确标记“仍占时长”）与新时间轴 SRT 预览；**存在格式错误（逐行标出行号与原因）、上游合并结果不可导出或剪辑结果为空时禁止下载**，全部通过后点击「下载剪辑版 SRT」得到独立的 `edited.srt`（序号从 1 重新编排）。
11. **字幕遮挡避让（可选，独立模块）**：切换到「字幕遮挡避让」页签，在文本框**逐行填写遮挡区间**（每行三项：`起点毫秒 终点毫秒 上/下`，起止为非负整数且起点小于终点，位置兼容 上轨/下轨/top/bottom，也可上传文本文件）。系统**只读**当前最终合并字幕的时间与文本（不改动合并结果、不改变 SRT），按**半开区间**相交判定每条字幕被遮挡的轨道（端点相接不算遮挡），随后用全局动态规划为每条字幕在上、下两条轨道中选一条：**默认下轨，先最少化相邻字幕切换轨道的次数，再最少化改到上轨的条数，并列时按字幕顺序优先下轨**。页面展示每个遮挡区间命中的条数、每条字幕的轨道分配与遮挡依据（哪一行遮挡了哪条轨道 / 双轨可用默认下轨 / 为减少切换改到上轨）；**任一字幕两轨均被遮挡时，只展示第一条无解字幕的原因，不生成也不导出任何部分方案**；存在格式错误（逐行标出行号与原因）或上游不可导出时同样禁止下载。全部通过后点击「下载轨道分配 CSV」得到独立的 `tracks.csv`（含字幕序号、起止时间与轨道，带 UTF-8 BOM）。
12. **术语统一（可选，独立模块）**：切换到「术语统一」页签，在文本框**粘贴或点击「上传术语文件」**导入术语表，**每行两列，以 Tab 分隔**：原词与替换词；两列均须非空、均不能含 `<...>` 标签；列数错误（多列/缺列）、空列、含标签或**原词重复**（仅首行生效）都会逐行标出行号与原因。系统**只读**当前最终合并字幕生成一份规范化副本，**绝不修改合并结果**：匹配**区分大小写**、按**字面量与 Unicode 字素簇**处理（不做大小写、标点或空白归一），**跳过 `<...>` 标签与换行建立匹配序列、其本身原样保留**（标签之间的文本仍是普通文本）；自左向右扫描，在当前起点选**最长原词**命中，命中后**整段越过**（不重叠、不嵌套），在**首个命中字素处插入替换词并删去其余命中字素**，段内标签与换行原位保留，**替换内容不再参与匹配**。页面逐条展示规范化前/后文本与命中规则（含术语表行号），并汇总变化条数与命中次数；术语表输入或上游结果（冲突解决、消重、断行、节奏、吸附、自动修复开关等）一旦变化立即重算。下载必须同时满足**术语表无错误行且至少一条有效规则**与**上游合并结果可导出**（`canExport`：无未解决冲突与校验错误且非空），文件名 `terms.srt`（带 UTF-8 BOM，序号从 1 重新编排）；**时间、条数与原合并结果完全一致**。
13. **审校定位（可选，独立模块）**：切换到「审校定位」页签，在文本框输入要定位的**原文短语**，并填写**允许跨条的最大时间间隔**（非负整数毫秒，默认 `0`）。系统**只读**当前最终合并字幕即时检索、**绝不修改合并 SRT**：按 **Unicode 字素簇区分大小写逐字匹配**（标点与空格必须逐字相同，不做任何归一；仅剥离开头 BOM、统一 CRLF，不 trim），字幕中的 `<...>` 标签与换行符不参与匹配但在结果中**原样显示**（标签之间的文本仍是普通文本，不带 `>` 的孤立尖括号按普通字符处理）；短语可在**相邻条目**间延续，仅当 `下一条开始 − 上一条结束 ≤ 间隔阈值` 时才允许跨过该边界，超阈必须中断，穿过没有任何可匹配字素的空条目（如只有标签/换行）时对沿途每对相邻条目逐跳检查、任一跳超阈即断。**重复出现（含互相重叠）的命中全部列出**，按出现顺序逐项展示**起止条目（界面序号从 1 起）、整体时间范围（起始条开始 → 结束条结束）与各条命中字素高亮**（标签与换行原样、不高亮；跨条命中另标出相邻间隔毫秒）。短语为空或间隔不是非负整数毫秒时，页面说明原因并**清空命中**；短语、间隔或上游最终字幕（冲突解决、消重、断行、节奏、吸附、自动修复开关等）一旦变化立即重算。

## 时间轴校准说明

- **候选锚点**：两侧文本各自归一化（去标签/标点/空白、小写化）后构建 bigram 倒排表粗筛，再按 bigram Dice 系数精选，默认要求相似度 ≥ 0.6、归一化文本 ≥ 4 字；阈值与最短长度可在界面调整。
- **剔除顺序冲突**：候选锚点构成 (A 下标, B 下标) 匹配，用树状数组做带权（相似度）最长递增子序列，保证保留下来的锚点两侧下标均严格递增且一对一；落选候选标记「顺序冲突」并展示。
- **剔除异常偏移**：对顺序一致的锚点拟合 **Theil–Sen 稳健直线**（全部点对斜率的中位数 + 截距中位数，对个别异常点不敏感），残差超过 `max(偏移容忍, 3.5·1.4826·MAD + 100ms)` 的最差锚点迭代剔除（至少保留两个），被剔除者标记「异常偏移」。
- **分段线性映射**：相邻启用锚点连成线性区段，`A = a0 + slope·(B − b0)`，斜率钳制在 [0.5, 2]；首尾之外的时间按最近区段斜率外推。映射结果四舍五入取毫秒，并逐条保证开始时间不早于上一条、结束时间严格大于开始（时长为正）。
- **残差展示**：每个启用锚点显示**留一法残差**（用其余锚点分段预测其 B 时间对应的 A 时间与实际之差），顶部给出全部锚点的 RMS 与最大绝对残差；被禁用/自动剔除的锚点显示相对当前映射的偏差。禁用单个锚点后映射、区段、残差与 B 新时间列即时重算。
- **应用与恢复**：校准页的任何调整都是预览；「应用校准并开始对齐」才把映射后的 B 时间轴提交到后续对齐链路，「恢复原始 B 时间并对齐」一键回到原始时间。校准结果透明地进入现有的顺序对齐、冲突解决、消重、断行与导出链路，后续步骤的所有规则不变。

## 重新校准迁移说明

- **入口与保留**：工作区顶部「重新校准并迁移决定」按钮进入迁移校准页；进入时当前对齐组、人工 A/B/自定义文本选择与单边保留/丢弃决定全部保留，弹窗确认前不会改动工作区（重新对齐与迁移预览在 Web Worker 中计算，计算中可点「取消计算」终止），点「取消」（或校准页「← 取消，保留旧工作区」）即原样返回，人工决定与消重 / 断行 / 节奏 / 吸附等下游采纳均不丢失。
- **可匹配条件**：旧对齐组与新对齐组仅在 **A 侧各 cue 原文按顺序拼接的文本**与 **B 侧拼接文本均完全相同**时才可配对（单边组只比较其存在的一侧，故仅 A 组不会与 1:1 组误配）；比较使用原始字幕文本，校准只改 B 的时间、不改文本。
- **全局最优、不交叉**：在所有可配对上求**组数最多的顺序一对一匹配**（对“组内容符号序列”求最长公共子序列 LCS），配对保持两侧组顺序、绝不交叉；合并组（N:1 / 1:N）按其双侧拼接文本整体参与比较，拼接不同则视为不同组。
- **唯一对应才迁移**：借助前向 / 后向 LCS DP 枚举每个旧组在**所有最优方案**中的配偶：只有“恰好一个配偶、且不存在跳过该旧组的最优方案”时才迁移；有多个可能配偶（`multi-partner`，典型为重复台词）或存在跳过它的同分方案（`skip-optional`）时一律标记歧义、按新组默认处理，**绝不按出现下标猜配**；没有任何配偶的旧组列为“无对应”。
- **迁移内容**：匹配组迁移其 **A / B / 自定义文本选择及自定义文本**，单边组迁移**保留 / 丢弃**决定；**局部混编的逐片段选择不迁移**（其分段依赖该组双侧文本的 LCS，重新对齐后可能变化，新组按默认状态处理）；旧组本身尚未处理（如未解决冲突）时不覆盖新组默认。**时间选择（A/B/并集/自定义时间）一律使用新组默认值**；消重、断行、阅读节奏与切点吸附的采纳全部清空。
- **提交后**：新工作区继续现有的冲突处理、消重、断行、节奏、吸附、实时预览与校验导出流程，规则不变；新组无旧对应的按默认状态出现，仍需人工处理的冲突照常标红拦截导出。顶部「时间轴已校准（N 锚点）」标识与生效 B 时间轴一起更新——确认的是「用原始 B 时间」预览时显示「使用原始 B 时间」。
- **校准标识不被草稿污染**：从工作区进入迁移校准页后，顶部已校准标识（是否校准 + 锚点数）与实际生效的 B 时间轴、审校决定绑定的是**上一次提交**的快照；调整锚点 / 筛选参数、预览计算中、计算失败（可「重新计算」）或「← 取消，保留旧工作区」返回都不会改变它，弹窗中说明的校准参数同样是发起本次预览时固化的那一份。只有确认预览提交后才更新为新快照。

## 局部混编说明

- **入口与适用范围**：双侧对齐组（一对一 / 一对多 / 多对一）的「保留文本」行在「版本 A / 版本 B」与「自定义」之间提供「**局部混编**」选项；单边组（仅 A / 仅 B）无两侧文本可比，不显示该入口。
- **字素级 LCS**：把该组 A 侧各 cue 原文按顺序拼接、B 侧同样拼接，两边按 **Unicode 字素簇（grapheme cluster，emoji 组合序列、带附加符字母等均算一个字素）** 求最长公共子序列。LCS 命中的字素组成**相同片段，固定保留、不可改选**；两次相邻匹配之间未命中的区域是一个**差异片段**，其中 A 有 B 无为删除、B 有 A 无为插入，两侧皆有则为替换，每个差异片段都可单独点选取 A 或取 B（取到空串即删除该段，界面以 `∅` 表示）。
- **多最优路径固定**：存在重复词等情况时，同样长度的 LCS 可能有多条。系统只取**匹配位置序列字典序最小**的一条——先逐对比较匹配到的 A 字素下标（小者优先），A 下标序列相同再比 B 下标序列；实现上用后缀长度 DP 加“下一对匹配位置”表（行优先编码的最小值，行优先顺序正好对应先 A 后 B）。该规则对相同输入给出唯一分段，重复词不会使片段边界漂移。
- **即时生效**：每次点选都即时拼接出本组文本（相同片段 + 各差异段当前选择），卡片内展示混编结果，且该组立即标记为**已解决冲突**，文本直接进入右侧实时预览、时间单调性校验与 SRT 导出（混编只决定文本，时间轴仍按该组的时间轴选择）。
- **失效与清除**：改选整组「版本 A / 版本 B / 自定义」、或重新对齐（放弃工作区重做、跳过校准）时旧的逐片段选择全部清除；**重新校准迁移**不迁移局部混编选择（其分段依赖该组双侧文本的 LCS，重新对齐后可能变化），新组按默认状态出现，仍需处理的冲突照常标红拦截导出。
- **规模保护**：两侧字素数乘积超过上限（400 万 DP 单元）的组不提供局部混编入口，仍可用 A / B / 自定义解决。

## 滚动字幕消重说明

- **相邻判定**：按合并结果出现顺序，下一条开始时间不早于上一条，且间隔 `下一条开始 − 上一条结束 ≤ 最大相邻间隔`（毫秒；负值表示两条显示时间重叠）。
- **重叠口径**：文本去除 HTML 标签（`<i>` 等）、ASS 覆盖标签（`{\an8}` 等）、标点与空白后得到字符序列（按 Unicode 码点切分，保留大小写）；相邻两项取**前一条最长后缀 ↔ 后一条最长前缀**的重叠长度（对后者建 KMP 前缀函数计算），重叠长度达到「最小文本重叠」才允许连接。
- **全局动态规划**：把每条可连接的相邻边视为带权区间（权重 = 重叠字符数），用带权区间调度 DP 选择**互不重叠的连续链**，按字典序依次：① 最大化累计消除的重复字符数；② 最小化合并组数（链数）；③ 同分时取更早链（链首下标更小，再依次比较链末与后续链）。
- **合并规则**：每条链只在首条全文之后依次追加后续各项**原文重叠位置之后的新增尾部**（标签、标点、空白按原文位置原样保留）；合并后时间取**链首条开始与末条结束**，序号在导出时统一重排。
- **采纳与恢复**：链的识别结果随参数与上游合并结果实时重算；每条链可单独采纳/恢复，也可全部采纳/全部恢复。参数变化后已失效的旧采纳自动忽略。预览与导出只使用已采纳的消重结果，智能断行在消重后的序列上进行。

## 智能断行说明

- **宽度计量**：按 Unicode 字素簇（grapheme cluster）计算显示宽度——全角字符计 2、半角计 1；HTML 标签（`<i>` 等）与 ASS 覆盖标签（`{\an8}` 等）原样保留在文本中但不计入宽度。
- **断点选择**：动态规划在空白或标点边界选择断点，依次最小化：① 超限宽度（超出每行最大宽度的总量）；② 行宽差（最窄行尽量宽、最宽行尽量窄）；③ 避头尾惩罚——行首为「，。！？；：、）】》」或行尾为「（【《」。
- **手工换行**：勾选「锁定已有手工换行」后，原文已有的换行作为不可跨越的边界（每段独立参与整体优化）；取消勾选则把已有换行当作普通空白，允许重新合并分行。
- **限制无法满足时**：若最优方案仍超宽（存在无法在空白/标点处断开的长片段）或所需行数超过上限，该条目标明原因且不应用，导出时保持原文；其余条目不受影响。
- **批量与逐条**：「全部应用」作用于所有可满足限制的条目；任意已应用条目可单独「恢复」为原文，「全部恢复」一键清空。修改参数后所有预览即时重算，导出始终使用当前文本。

## 阅读节奏说明

- **统计口径**：字符按 Unicode 字素簇计数——去除 HTML 标签（`<i>` 等）与 ASS 覆盖标签（`{\an8}` 等），空白（含换行）不计入、标点计入；时长 = 结束 − 开始；字符/秒 = 字符数 ÷ 时长（秒）。
- **超限判定**：字符/秒超过上限（超速）、时长低于最短时长（过短）或超过最长时长（过长），满足其一即超限；下标连续的超限条划为同一区段，正常条打断区段。
- **修复模型**：区段左界为前一条结束时间（首条为 0）、右界为后一条开始时间（末条无界）。每条所需最短时长 = max(最短时长, ⌈字符数 ÷ 最大字符每秒⌉)，期望时长 = clamp(原时长, 所需最短时长, 最长时长)。Σ最短时长 ≤ 可用窗口时可解：先按原开始时间顺序前向摆放（不重叠、不早于左界），末端超出右界时再从右界整体回推（只左移必要的条，借用区段前空隙）；若期望时长总和超窗，把超出部分按各条富余比例压缩（最大剩余法取整，仍满足全部下限与最长时长）。修复不改文本、不打乱顺序、时间不重叠。
- **无解标记**：单条所需最短时长超过最长时长（字符/秒与最长时长冲突），或区段 Σ最短时长超过前后边界间的可用窗口时，该区段明确标记无解与原因，保持原时间。
- **采纳与失效**：以区段为单位采纳/恢复，也可全部采纳/全部恢复；采纳 key 与成员及修复后时间绑定，上游（冲突解决、消重、断行）或参数变化导致修复结果不同时，旧采纳自动失效。已采纳时间进入右侧实时预览与 SRT 导出。

## 镜头切点吸附说明

- **切点输入**：文本框粘贴或文件上传，每行一个 `HH:MM:SS,mmm`（复用 SRT 时间码解析，兼容 `MM:SS,mmm`、小数点与 1~3 位毫秒）；自动去 BOM、忽略空行、**升序去重**，无法解析的行按行号列出原文，不影响其余切点参与计算。
- **候选生成**：每条字幕的开始/结束边界各生成候选位置 = 原位置 + 与其距离不超过**吸附阈值**的切点；切点恰在原边界上视为“已在切点”，该条不算跨镜头、也不产生位移。
- **跨镜头口径**：切点严格位于字幕开区间 `(开始, 结束)` 内才算该条跨镜头；切点恰在边界上不算（这正是吸附要达到的状态）。
- **全局动态规划**：按字幕顺序推进，阶段状态为该条结束边界选取的候选位置，转移枚举开始候选 `s` 与结束候选 `e`，只接受满足 `s ≥ 上一条选定结束`（保持顺序、相邻不重叠）与 `e − s ≥ 最短时长` 的组合；上一阶段的最优前缀用“按结束位置排序的前缀最小值 + 二分”取得。方案按字典序依次最小化：① **跨镜头字幕数**；② **边界总位移**（各边界 |新−原| 之和）；③ **改动条数**。最优方案只会把边界向区间内侧收缩，因此逐条采纳是子集安全的——采纳任意子集都不会制造相邻重叠。
- **无解情形**：吸附只能收缩边界，故某条原时长已短于最短时长、或原始相邻重叠超过阈值内切点的最大可收缩量时，没有可行方案；页面明确提示原因，所有条目保持原时间且不可采纳。
- **逐条展示与采纳**：每条展示原/新开始结束时间、命中切点与带符号位移、新时长，以及每个未移动边界的**未吸附原因**（阈值内无切点、吸附后短于最小时长、吸附会与相邻条重叠、未跨切点吸附只增加位移、吸附后仍跨越其他切点等）。可逐条采纳/恢复，也可全部采纳/全部恢复；采纳 key 由 `groupIndex + 原时间 + 新时间` 构成，**切点列表、阈值/最短时长或上游结果（冲突解决、消重、断行、节奏）变化**使方案不同时，旧采纳自动失效。右侧预览、校验清单与 SRT 导出只使用已采纳吸附结果。

## 剪辑版字幕说明

- **定位**：独立的下游模块，**只读取**校验导出链路的最终字幕（已采纳消重、断行、节奏与切点吸附后的 `finalCues`），不保存任何采纳状态、也绝不写回或修改合并结果；原「下载合并 SRT」与剪辑版互不影响。
- **片段输入**：每行两个非负整数毫秒（`起点 终点`，起点严格小于终点），物理行号即报错行号；空行忽略。支持空白/Tab、英文/中文逗号、英文/中文分号、箭头 `-->`、波浪号等分隔；小数、负数、列数不对（少于或多于两个数字）、起点 ≥ 终点均按行标出原因。
- **顺序与重复**：片段**不排序、不去重**，行序即成片顺序；同一区间重复填写会重复出现，区间允许互相重叠、也允许早于/晚于当前位置倒序填写。
- **时间轴重排**：片段按各自原时长（`终点 − 起点`）首尾拼接，片段 k 的成片起点 = 此前所有片段时长之和。对每条字幕与每个半开区间 `[segStart, segEnd)` 求交（切点恰好落在边界上不算跨片段），仅保留正时长交集；新时间 = `交集起点 − 片段起点 + 此前片段总时长`，结束同理，**文本原样复制**。
- **输出口径**：跨多个片段的字幕在每个命中片段分别输出一条；重复片段命中同一字幕会重复输出；**空白片段（无任何命中）仍占用时长**，只是不产生字幕；相邻同文字幕**不做任何合并**；输出顺序为片段顺序 × 片段内原字幕顺序，SRT 序号在下载时从 1 重新编排。
- **即时重算与下载门槛**：片段文本或上游结果（冲突解决、消重、断行、节奏、吸附、自动修复开关等）一旦变化立即重算预览。下载剪辑版 SRT 必须同时满足：片段列表**无格式错误**且至少一个片段、**上游合并结果可导出**（无未解决冲突与校验错误且非空）、剪辑版结果**非空**（所有片段都与字幕不相交时即使片段合法也禁止下载）。下载文件名为 `edited.srt`（带 UTF-8 BOM）。

## 字幕遮挡避让说明

- **定位**：独立的下游模块，**只读取**校验导出链路的最终字幕（已采纳消重、断行、节奏与切点吸附后的 `finalCues`）的时间与文本，不保存任何采纳状态、也绝不写回或修改合并结果；导出的只是轨道分配 CSV，**不改变 SRT 本身**。
- **遮挡输入**：每行三项（`起点毫秒 终点毫秒 位置`），起止为非负整数毫秒且起点严格小于终点，位置为 `上` 或 `下`（兼容 `上轨`/`下轨`/`top`/`bottom`，英文不区分大小写）；物理行号即报错行号，空行忽略。支持空白/Tab、英文/中文逗号、英文/中文分号、箭头 `-->`、波浪号等分隔；小数、负数、列数不对、起点 ≥ 终点、位置无法识别均按行标出原因。
- **遮挡判定**：遮挡区间与字幕按**半开区间** `[start, end)` 求交，有正时长交集时该位置（轨道）对这条字幕不可用；端点相接（遮挡终点恰等于字幕起点，或反之）不算遮挡。
- **轨道分配**：每条字幕默认下轨。用动态规划在全部字幕上求全局最优，目标按字典序依次：① **最少化相邻字幕切换轨道的次数**；② **最少化改到上轨的条数**；③ 仍有并列时**按字幕顺序优先下轨**（位置靠前的字幕尽量放下轨）。例如某条双轨可用的字幕夹在两条只能上轨的字幕之间时，为把切换次数降到 0 会被分配到上轨。
- **无解**：任一字幕上、下两轨均被遮挡时整体无解，页面只展示**第一条**无解字幕的序号、时间与两轨各自的遮挡行号，不生成、也不导出任何部分方案。
- **预览与下载**：页面展示每个遮挡区间命中的字幕条数，以及每条字幕的轨道（上/下）与遮挡依据（被哪一行遮挡而只能走某条轨道、双轨可用默认下轨、或为减少切换改到上轨），并汇总上轨条数、下轨条数与切换次数。下载轨道 CSV 必须同时满足：遮挡列表**无格式错误**、**上游合并结果可导出**、**存在完整方案**；下载文件名为 `tracks.csv`（带 UTF-8 BOM），含字幕序号（从 1 起）、开始时间、结束时间（`HH:MM:SS,mmm`）与轨道（上/下）四列。

## 术语统一说明

- **定位**：独立的下游模块，**只读取**校验导出链路的最终字幕（已采纳消重、断行、节奏与切点吸附后的 `finalCues`），不保存任何采纳状态、也绝不写回或修改合并结果；原「下载合并 SRT」与术语统一副本互不影响，**规范化副本的时间、顺序与条数和上游完全一致**。
- **术语表输入**：**每行恰好两列，以 Tab（`⇥`）分隔**——原词与替换词；只剥离开头 BOM 与统一换行为 `\n`，**不 trim、不做大小写/标点/空白归一**，因此列两侧的空格也属于词面。空行忽略，物理行号即报错行号。下列情况逐行标出原因：列数错误（少于两列缺 Tab、多于两列含多余 Tab）、任一列空、原词或替换词包含 `<...>` 标签；**原词重复时仅首行规则生效，后续重复行逐行提示“与第 N 行重复”且不覆盖首行**。
- **匹配序列**：先把每条文本切成原子——`<...>` 标签与换行符（`\n`）是**不参与匹配的跳过段**，其余按 **Unicode 字素簇**（grapheme cluster，emoji ZWJ 序列、带附加符字母等均为一个不可拆整体）切分，形成纯字素匹配序列；跳过段在输出中**原位原样保留**。注意跳过的只是标签尖括号部分本身，**标签之间的文本（如 `<i>x</i>` 里的 `x`）仍是普通文本**参与匹配；不带 `>` 的孤立尖括号按普通字符处理。
- **扫描与最长匹配**：自左向右推进，在每个字素起点同时尝试全部规则，取能命中的**最长原词**（按字素个数计；长度相同时不会出现两条规则，因为重复原词已被拒绝）。命中后扫描位置**整段越过该原词**，因此命中之间不重叠、不嵌套；插入的替换词**只进入输出、不再进入匹配序列**，即便替换词文本恰好等于某条原词也不会发生连锁替换。
- **命中段改写**：命中段的**第一个命中字素位置整体替换为替换词**，段内其余命中字素删除；段中跨过的标签与换行仍按原位置保留（例如 `a<i></i>b\nc` 命中 `abc` → `X` 得 `X<i></i>\n`）。未命中的字素与全部跳过段逐字原样输出，故无规则命中时结果与原文严格相等。
- **即时重算与下载门槛**：术语表文本或上游 `finalCues` 一旦变化（含冲突解决、消重、断行、节奏、吸附、自动修复开关等）立即通过响应式记忆重算，无需任何提交动作。页面逐条展示**规范化前/后文本**与本条**命中规则**（原词 ⇒ 替换词及术语表行号），未命中条目标为“未变化”，并汇总有效规则数、变化条数与命中总次数。下载 `terms.srt` 必须同时满足：**术语表无错误行且至少一条有效规则**、**上游 `canExport` 为真**（无未解决冲突与校验错误且结果非空）；文件带 UTF-8 BOM，SRT 序号从 1 重新编排。

## 审校定位说明

- **定位**：独立的下游模块，**只读取**校验导出链路的最终字幕（已采纳消重、断行、节奏与切点吸附后的 `finalCues`），不保存任何采纳状态、也绝不写回或修改合并结果；没有下载动作，检索过程对合并 SRT 零影响。
- **短语输入**：文本框直接输入原文短语，仅剥离开头 BOM 与统一 CRLF 为 `\n`，**不 trim、不做大小写/标点/空白归一**；区分大小写，标点与空格（含全角/半角）必须与字幕逐字相同。**跳过标签与换行的规则只作用于字幕侧**：短语自身包含换行时按字面量处理，无法命中一条内被换行隔开的文本（跨条命中需短语字素分别落在相邻条目的正文中）。
- **匹配序列**：每条字幕先切成原子——`<...>` 标签与换行符 `\n` 是**不参与匹配的跳过段**，其余按 **Unicode 字素簇**（emoji ZWJ 序列、带附加符字母等均为一个不可拆整体）切分，各条按顺序拼成纯字素流；跳过段在高亮展示时**原位原样保留**。标签之间的文本（如 `<i>x</i>` 里的 `x`）仍是普通文本，不带 `>` 的孤立尖括号按普通字符处理。
- **跨条中断**：字素流只在**相邻条目**之间连续。从条目 c−1 跨入 c 时检查 `cues[c].start − cues[c−1].end`，严格大于阈值即为不可跨越的断点（恰等于阈值允许跨越）；中间没有任何可匹配字素的条目（空串或只有标签/换行）不提供字素，但短语穿过它时仍要对沿途**每一对**相邻条目逐跳检查，任一跳超阈即中断。阈值为非负整数毫秒（`0` 表示仅首尾相接可跨）。
- **命中口径**：用 KMP 在线性扫描中枚举**全部**命中，互相重叠的命中也分别列出（如 `aaaa` 搜 `aa` 得 3 处），按开始位置排序。每处命中给出起始/结束条目（界面序号从 1 起）、整体时间范围（起始条开始 → 结束条结束），并按条给出该条命中部分的时间与**命中字素高亮**（仅命中的普通字素加亮，标签/换行与未命中字素原样显示）；跨多条的命中在相邻两条之间标出实际间隔毫秒。
- **输入校验与即时重算**：短语为空时提示“短语为空”，间隔为空、小数、负数或非整数时提示“必须是非负整数毫秒”，两种情况下均**不产出任何命中**（短语为空优先报短语错误）。短语、间隔文本或上游 `finalCues` 一旦变化（含冲突解决、消重、断行、节奏、吸附、自动修复开关等）立即通过响应式记忆重算，无需提交动作。

## 对齐算法说明

- 文本归一化：去除 HTML/ASS 标签、标点与空白后小写化，对中英文均适用；相似度采用 bigram Dice 系数。
- 时间重叠：两时间段交集的 Dice 系数。
- 顺序对齐：带合并移动的动态规划（类序列比对），每个位置允许 1:1 匹配、N:1 合并、1:N 合并（单侧最多连续 4 条）与跳过（产生单边片段），全局最大化累计得分；大文件自动切换带状 DP 控制计算量。
